sidebarTitle: "Mosaics"

---

Mosaics are column-based grid layouts that you build in the VAMS drag-and-drop editor. Each mosaic contains an ordered collection of items placed across one or more columns. An item can be an image, a linked tile, or any other content type you configure — the `type` field identifies it, and the `content` object holds the payload. The Mosaics API exposes three read-only endpoints: list all mosaics, fetch one by UUID (with its items), and look up one by title.

---

## List All Mosaics

Returns all mosaics belonging to your account. Item data is **not** included in this list response — use [Get Mosaic by ID](#get-mosaic-by-id) to fetch a mosaic with its full item tree.

```
GET /api/mosaics
```

### Response Fields

<ResponseField name="success" type="boolean">
  Always `true` for a successful response.
</ResponseField>

<ResponseField name="message" type="string">
  A human-readable status message, e.g. `"Mosaics retrieved successfully"`.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="mosaics" type="array">
      Array of mosaic metadata objects.
      <Expandable title="mosaic object">
        <ResponseField name="id" type="string">
          UUID of the mosaic.
        </ResponseField>
        <ResponseField name="title" type="string">
          Mosaic title.
        </ResponseField>
        <ResponseField name="description" type="string | null">
          Optional description text.
        </ResponseField>
        <ResponseField name="columns" type="integer">
          Number of columns in the grid layout (between 2 and 5).
        </ResponseField>
        <ResponseField name="user_id" type="string">
          UUID of the account that owns this mosaic.
        </ResponseField>
        <ResponseField name="created_at" type="string">
          ISO 8601 timestamp of when the mosaic was created.
        </ResponseField>
        <ResponseField name="updated_at" type="string">
          ISO 8601 timestamp of the most recent update.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

### Examples

<CodeGroup>

```javascript JavaScript
const res = await fetch('https://<your-vams-domain>/api/mosaics', {
  headers: { 'X-API-Key': 'your-api-key-here' }
});
const data = await res.json();
console.log(data.data.mosaics);
```

```bash curl
curl https://<your-vams-domain>/api/mosaics \
  -H "X-API-Key: your-api-key-here"
```

</CodeGroup>

## Get Mosaic by ID

Returns a single mosaic — identified by its UUID — together with its full list of items ordered by `column_index` and then by `order`.

```
GET /api/mosaics/{id}
```

### Path Parameters

<ParamField path="id" type="string" required>
  The UUID of the mosaic to retrieve.
</ParamField>

### Response Fields

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="mosaic" type="object">
      The mosaic metadata object. Same fields as described in [List All Mosaics](#list-all-mosaics).
    </ResponseField>
    <ResponseField name="items" type="array">
      Ordered array of mosaic item objects.
      <Expandable title="item object">
        <ResponseField name="id" type="string">
          UUID of the mosaic item.
        </ResponseField>
        <ResponseField name="type" type="string">
          Content type of this item, e.g. `"image"` or `"album"`.
        </ResponseField>
        <ResponseField name="content" type="object | array | null">
          The item's content payload. Structure depends on `type`:
          <Expandable title="content fields (image type)">
            <ResponseField name="image_url" type="string">
              URL of the image to display.
            </ResponseField>
            <ResponseField name="title" type="string | null">
              Optional overlay title for the tile.
            </ResponseField>
            <ResponseField name="description" type="string | null">
              Optional overlay description.
            </ResponseField>
            <ResponseField name="link" type="string | null">
              Optional URL the tile should link to when clicked.
            </ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="properties" type="object | null">
          Arbitrary display properties stored with the item (e.g. custom styles or layout hints).
        </ResponseField>
        <ResponseField name="column_index" type="integer">
          Zero-based index of the column this item occupies in the mosaic grid.
        </ResponseField>
        <ResponseField name="order" type="integer">
          Sort order within its column (ascending).
        </ResponseField>
        <ResponseField name="created_at" type="string">
          ISO 8601 creation timestamp.
        </ResponseField>
        <ResponseField name="updated_at" type="string">
          ISO 8601 last-updated timestamp.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

### Examples

<CodeGroup>

```javascript JavaScript
const mosaicId = '018f2b3c-4d5e-6f7a-8b9c-0d1e2f3a4b5c';

const res = await fetch(`https://<your-vams-domain>/api/mosaics/${mosaicId}`, {
  headers: { 'X-API-Key': 'your-api-key-here' }
});
const data = await res.json();
const { mosaic, items } = data.data;

// Group items by column for rendering
const columns = {};
for (const item of items) {
  if (!columns[item.column_index]) columns[item.column_index] = [];
  columns[item.column_index].push(item);
}
```

```bash curl
curl https://<your-vams-domain>/api/mosaics/018f2b3c-4d5e-6f7a-8b9c-0d1e2f3a4b5c \
  -H "X-API-Key: your-api-key-here"
```

## Get Mosaic by Title

Returns a single mosaic — together with its items — looked up by its title. Matching is **case-insensitive**; the API tries an exact match first, then falls back to a case-insensitive comparison.

```
GET /api/mosaics/by-title/{title}
```

### Path Parameters

<ParamField path="title" type="string" required>
  The title of the mosaic. URL-encode spaces and special characters (e.g. `Portfolio%20Homepage`).
</ParamField>

### Examples

<CodeGroup>

```javascript JavaScript
const title = encodeURIComponent('Portfolio Homepage');

const res = await fetch(`https://<your-vams-domain>/api/mosaics/by-title/${title}`, {
  headers: { 'X-API-Key': 'your-api-key-here' }
});
const data = await res.json();
console.log(data.data.mosaic);
console.log(data.data.items);
```

```bash curl
curl "https://<your-vams-domain>/api/mosaics/by-title/Portfolio%20Homepage" \
  -H "X-API-Key: your-api-key-here"
```

</CodeGroup>

<Tip>
  Title lookup is handy when you want to reference a named mosaic (e.g. `"Homepage"`) from your frontend config without tracking UUIDs. Because matching is case-insensitive, `homepage`, `Homepage`, and `HOMEPAGE` all resolve to the same mosaic.
</Tip>

The response shape is identical to [Get Mosaic by ID](#get-mosaic-by-id) — a `data` object containing `mosaic` and `items`.
