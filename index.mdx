Welcome to VAMS — a headless content management system purpose-built for visual creators. Whether you're a photographer organizing shoots, a designer curating portfolio layouts, or a creative studio managing client work, VAMS gives you a single place to store and structure your visual content, then exposes it all through a clean, read-only API so any website or app can consume it instantly.

## Get up and running in three steps

<Steps>
  <Step title="Sign up for an account">
    Create your VAMS account and log in to the dashboard. Your personal API key is generated automatically and is available in your profile settings the moment you sign in.
  </Step>
  <Step title="Upload your content">
    Create your first album, add images, and optionally build a mosaic layout. Publish the album when you're ready for it to appear in API responses.
  </Step>
  <Step title="Connect via API">
    Copy your API key from your profile, then start fetching your content from any frontend using the `X-API-Key` header. No backend code required on your end.
  </Step>
</Steps>
